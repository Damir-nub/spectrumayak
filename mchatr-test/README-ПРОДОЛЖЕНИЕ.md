## КЛЮЧЕВЫЕ ФУНКЦИИ ДЛЯ РЕДАКТИРОВАНИЯ:

### `showResults()` — отображение результатов

- Показывает инфо о ребёнке + результаты всех методик + интегрированную рекомендацию

### `generateIntegratedConclusion()` — ИТОГОВАЯ РЕКОМЕНДАЦИЯ

- **САМАЯ ВАЖНАЯ ФУНКЦИЯ** — анализирует все методики, создаёт план действий
- Вызывает `getFBADetails()` для behavioural recommendations
- Вызывает `getGeneralAnalysis()` для общего заключения

### `calculateMethodScore(method)` — подсчёт результата методики

- Switch-case для каждой методики (mchatr, fast, scq, default)
- Возвращает {score, description, riskClass, recommendation}

### `generatePDF()` — создание PDF

- Создаёт чистый контейнер с результатами
- Включает инфо о ребёнке + все методики + интегрированную рекомендацию
- НЕ включает навигацию/прогресс-бар (решена проблема пустой первой страницы)

### `getFBADetails(funcName)` — детали для FBA

- Конкретные шаги для каждой функции поведения (attention, escape, tangible, sensory)
