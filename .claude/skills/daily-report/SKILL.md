# Daily Report Skill

Собирает краткий технический отчёт за последние 24 часа по проекту СпектраМаяк.

## Что делает

1. **Читает git коммиты** за последние 24 часа — собирает статистику (количество коммитов, файлов, строк)
2. **Читает историю** из `.business/история/` за сегодня (по дате в названии файла)
3. **Анализирует планы** в `plans/`:
   - Сначала проверяет планы с сегодняшней датой в названии (YYYY-MM-DD-\*)
   - Потом все файлы в plans/, изменённые за последние 24 часа
   - Ищет закрытые фазы (маркер `[x]`)
4. **Формирует отчёт** в формате:
   - ✅ Сделано
   - 🔄 В процессе
   - 🚫 Заблокировано
5. **Выводит в консоль** + сохраняет в `.business/отчёты/YYYY-MM-DD.md`

## Когда использовать

Когда пользователь говорит:

- "собери отчёт за день"
- "дневной отчёт"
- "что сделано за сегодня"
- "/daily-report"

## Как запускать

Через Skill tool:

```
Use skill: daily-report
```

## Формат отчёта

```
# Ежедневный отчёт: 2026-04-26

## 📊 Статистика коммитов
- Коммитов: 5
- Файлов изменено: 12
- Строк добавлено: +234
- Строк удалено: -89

## ✅ Сделано
[список закрытых фаз из планов]

## 🔄 В процессе
[текущая работа из коммитов]

## 📝 История
[краткая выдержка из .business/история/]

## 🚫 Заблокировано
[если есть блокеры из коммитов или истории]
```

## Технические детали

- Временной период: последние 24 часа от текущего момента
- Git команда: `git log --since="24 hours ago" --pretty=format:"%h %s" --stat`
- Файлы планов ищутся по маске `plans/20*-*.md`
- История ищется по маске `.business/история/20*-*.md`
- Отчёт сохраняется в `.business/отчёты/YYYY-MM-DD.md` (создаёт папку при необходимости)
