```

- ФИО: Петров Артём Алексеевич
- Возраст: 2 года 6 месяцев

- Критические пункты: 5/20

- Углублённая диагностика ADOS-2

- Занятия с логопедом 2 раза в неделю
```

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Как это работает:

1. **Чтение PDF** — использует встроенный инструмент Read (поддерживает PDF до 20 страниц)
2. **Генерация PDF** — создаёт структурированный markdown, который можно конвертировать в PDF
3. **Импорт данных** — извлекает данные из PDF в формат JSON/текст

### Интеграция:

- Работает с [`spectrum-reports`](.claude/skills/spectrum-reports/) для генерации отчётов по методикам
- Использует [`frontend-design`](.claude/skills/frontend-design/) для визуального оформления
- Берёт данные из [`.business/`](.business/) о методиках и форматах

---

## 🎓 ПОДДЕРЖИВАЕМЫЕ МЕТОДИКИ

✅ **M-CHAT-R** (16-30 месяцев) — скрининг РАС
✅ **ADOS-2** (все модули) — углублённая диагностика
✅ **VB-MAPP** — оценка вербального поведения

Скопируйте эту команду:


Когда проводите диагностику:

- Соберите данные пациента

### Шаг 3: Получите готовый PDF

Я создам структурированный отчёт, который:
