# PDF Skill

Инструмент для работы с PDF файлами в проекте СпектраМаяк.

## Возможности

### 1. Чтение PDF файлов

Читает содержимое PDF файлов и извлекает текст.

**Когда использовать:**

- Нужно прочитать содержимое PDF документа
- Нужно извлечь текст из PDF для анализа
- Нужно получить данные из PDF шаблона

**Как использовать:**
Просто попросите: "Прочитай файл file.pdf" или "Извлеки данные из документа.pdf"

### 2. Генерация PDF отчётов

Создаёт структурированные PDF отчёты по диагностике РАС.

**Когда использовать:**

- Нужно создать заключение по M-CHAT-R
- Нужно сгенерировать протокол ADOS-2
- Нужно оформить отчёт VB-MAPP
- Нужно экспортировать результаты диагностики в PDF

**Как использовать:**

- "Создай PDF отчёт по диагностики пациента [имя]"
- "Экспортируй результаты M-CHAT-R в PDF"
- "Сгенерируй заключение в формате PDF"

**Включает:**

- Шапку с логотипом и датой
- Данные пациента
- Результаты тестирования
- Графики и таблицы
- Подписи специалиста

### 3. Импорт данных из PDF форм

Извлекает структурированные данные из PDF форм и шаблонов.

**Когда использовать:**

- Нужно импортировать данные из старых отчётов
- Нужно перенести данные из PDF шаблона в систему

**Как использовать:**

- "Импортируй данные из формы.pdf"
- "Извлеки результаты тестирования из документа.pdf"

## Поддерживаемые методики

Skill оптимизирован для работы с методиками проекта СпектраМаяк:

- **M-CHAT-R** — модифицированный чеклист для аутизма у малышей
- **ADOS-2** — шкала наблюдения для диагностики аутизма
- **VB-MAPP** — оценка вербального поведения и обучающихся навыков

## Примеры использования

### Прочитать PDF

```
"Прочитай файл protocols/patient-123-mchat.pdf"
```

### Создать отчёт по M-CHAT-R

```
"Создай PDF отчёт по M-CHAT-R для пациента Иванова,
результат: 7 баллов, риск средний"
```

### Генерация заключения с графиками

```
"Сгенерируй PDF заключение по ADOS-2 с графиками
показателей по модулям"
```

### Импорт исторических данных

```
"Извлеки данные пациента из старого отчёта old-report.pdf
и сохрани в новую систему"
```

## Технические детали

**Использует:**

- Встроенный инструмент Read для чтения PDF
- JavaScript библиотеки для генерации PDF (jsPDF, pdfkit)
- Парсеры для извлечения структурированных данных

**Форматы:**

- Вход: PDF
- Выход: PDF, текстовые данные, JSON

**Ограничения:**

- Максимальный размер PDF файла: 10 MB
- Количество страниц: до 20 (для чтения)
- Сложные формы: могут требовать ручной верификации
