## 🎯 Как пользоваться (ПРЯМО СЕЙЧАС)

### 1. ЧТЕНИЕ PDF — просто дайте команду

```
"Прочитай файл protocols/patient-001.pdf"
```

Я автоматически использую встроенный инструмент Read для чтения PDF.

### 2. СОЗДАНИЕ PDF ОТЧЁТОВ

**Простой пример:**

```
"Создай PDF отчёт по M-CHAT-R для пациента Иванова И.И., 3 года.
Результаты: не проходит 2 критических пункта из 20.
Заключение: низкий риск РАС"
```

**Сложный пример:**

```
"Создай комплексный PDF отчёт для пациента Петрова А.А.:

Пациент:
- ФИО: Петров Артём Алексеевич
- Возраст: 2 года 6 месяцев
- Дата: 26.04.2026

M-CHAT-R:
- Критические пункты: 3/20
- Риск: средний

VB-MAPP:
- Уровень: 1
- Навыки: beginning speaker

Рекомендации:
- Занятия с дефектологом
- Развитие имитационных навыков"
```

### 3. ИМПОРТ ДАННЫХ ИЗ PDF

```
"Извлеки данные пациента из файла old-report.pdf"
```

## 🔧 Интеграция с проектом

PDF Skill автоматически работает с:

- **[`.business/`](.business/)** — использует данные о методиках
- **[`spectrum-reports`](.claude/skills/spectrum-reports/)** — генерирует структурированные отчёты
- **[`frontend-design`](.claude/skills/frontend-design/)** — создаёт визуально оформленные документы

---

## 📊 Поддерживаемые методики

✅ **M-CHAT-R** — модифицированный чеклист для аутизма у малышей (16-30 месяцев)
✅ **ADOS-2** — шкала наблюдения для диагностики аутизма (все модули)
✅ **VB-MAPP** — оценка вербального поведения и обучающихся навыков

## 💡 Советы по использованию

### Для чтения PDF:

- Давайте полный путь к файлу
- Укажите, что именно извлечь (если нужно)

### для создания отчётов:

- Опишите пациента (ФИО, возраст)
- Перечислите результаты тестирования
- Укажите методику (M-CHAT-R, ADOS-2, VB-MAPP)
- Добавьте рекомендации (если есть)

### для импорта данных:

- Укажите файл PDF
- Опишите, какие данные нужны
- Я извлеку их в структурированном виде

---

## ✨ Возможности

1. **Чтение PDF** — извлекает текст из PDF файлов
2. **Генерация отчётов** — создаёт структурированные PDF заключения
3. **Импорт данных** — извлекает данные из PDF форм в структурированный формат
4. **Комплексные отчёты** — объединяет данные из нескольких методик
5. **Визуализация** — добавляет таблицы, графики, списки

## 🎓 Примеры из реальной практики

### Заключение по M-CHAT-R

```
"Создай PDF заключение по M-CHAT-R для пациента Сидорова А.А., 2 года 8 мес.

Критические пункты (не проходит):
- B2 — Не указывает на интересующие объекты
- B4 — Не приносит взрослому показать объекты
- B7 — Не подражает действиям взрослого

Заключение: средний риск РАС, рекомендовано углублённое обследование"
```

```

Дата: 26.04.2026
```
