# Примеры использования PDF Skill

## Демонстрация возможностей

### Пример 1: Чтение PDF файла

```bash
# Создам тестовый PDF файл для демонстрации
```

**Команда:**

```
"Прочитай файл protocols/test-mchat.pdf"
```

**Результат:**
Skill извлечёт текст из PDF и покажет содержимое.

---

### Пример 2: Генерация PDF отчёта по M-CHAT-R

```
"Создай PDF отчёт по M-CHAT-R для пациента Петрова Ивана, 3 года
Результаты:
- Не проходит мимо других детей
- Не указывает на интересующие объекты
- Не приносит взрослому показать объекты
Всего: 3/20 критических пунктов"
```

**Результат:**
Будет создан PDF файл с:

- Шапкой "СпектраМаяк - Заключение по M-CHAT-R"
- Данными пациента
- Результатами тестирования
- Заключением о риске
- Местом для подписи

---

### Пример 3: Импорт данных из PDF формы

```
"Извлеки данные пациента из old-report.pdf:
- ФИО
- Дата рождения
- Результаты по всем методикам"
```

**Результат:**
Skill извлечёт структурированные данные в формате JSON.

---

### Пример 4: Создание комплексного отчёта

```
"Создай комплексный PDF отчёт по пациенту Сидорову А.А.:
1. M-CHAT-R: низкий риск
2. VB-MAPP: уровень 1
3. Рекомендации: занятия с логопедом"
```

**Результат:**
PDF с графиками, таблицами и рекомендациями.

---

## Интеграция с проектом СпектраМаяк

Skill автоматически интегрируется с:

- [`.business/`](.business/) — использует шаблоны отчётов
- [`spectrum-reports`](.claude/skills/spectrum-reports/) — генерирует диагностические отчёты
- [`frontend-design`](.claude/skills/frontend-design/) — создаёт визуально оформленные PDF

## Быстрый старт

1. **Читать PDF:** просто дайте путь к файлу
2. **Создать отчёт:** опишите пациента и результаты
3. **Импортировать данные:** укажите что извлечь из PDF
