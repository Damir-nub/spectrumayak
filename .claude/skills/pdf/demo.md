## 🚀 Как пользоваться

### Способ 1: Прямые команды (автоматически)

Skill **автоматически активируется** когда вы просите:

#### Чтение PDF

```
"Прочитай файл protocols/patient-001.pdf"
"Извлеки текст из документа.pdf"
"Покажи содержимое отчёт.pdf"
```

#### Создание PDF отчётов

```
"Создай PDF отчёт по M-CHAT-R для Иванова И.И."
"Сгенерируй заключение по ADOS-2 в PDF"
"Экспортируй результаты диагностики в PDF"
```

#### Импорт данных

```
"Импортируй данные из old-report.pdf"
"Извлеки результаты тестирования из формы.pdf"
```

---

### Способ 2: Явный вызов через /pdf

```
/pdf создать отчёт M-CHAT-R для пациента Петрова
/pdf прочитать file.pdf
/pdf извлечь данные из report.pdf
```

## 📋 Реальные примеры для СпектраМаяк

### Пример 1: Создание заключения M-CHAT-R

**Запрос:**

```
"Создай PDF заключение по M-CHAT-R для пациента:
ФИО: Сидоров Артём Алексеевич
Возраст: 2 года 8 месяцев
Дата обследования: 26.04.2026

Критические пункты (не проходит):
- Не указывает на интересующие объекты
- Не приносит взрослому показать объекты
- Не подражает действиям взрослых

Итого: 3/20 критических пунктов"
```

**Результат:**
PDF файл с:

- Шапкой "СпектраМаяк — Заключение по методике M-CHAT-R"
- Данными пациента
- Список критических пунктов
- Интерпретацией: низкий риск РАС
- Рекомендациями
- Местом для подписи специалиста

---

### Пример 2: Комплексный отчёт

**Запрос:**

```
"Создай комплексный PDF отчёт для пациента Иванова М.П.:

M-CHAT-R: 2/20 (низкий риск)
VB-MAPP: Уровень 1 (ребёнок начинает обучаться)
ADOS-2: Модуль 1, балл 5 (в пределах нормы)

Рекомендации:
- Занятия с логопедом 2 раза в неделю
- Развитие навыков подражания
- Игры с другими детьми"
```

**Результат:**
Многостраничный PDF с графиками, таблицами и рекомендациями.

---

### Пример 3: Чтение существующего PDF

**Запрос:**

```
"Прочитай файл protocols/archives/old-report-001.pdf и извлеки:
- ФИО пациента
- Дату рождения
- Результаты по всем методикам
- Заключение специалиста"
```

**Результат:**
Структурированные данные в удобном формате.
