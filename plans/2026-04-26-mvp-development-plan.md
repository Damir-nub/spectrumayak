## Обзор

MVP (минимально жизнеспособный продукт) — веб-приложение (Web App) для автоматизации диагностики РАС с 1 методикой (M-CHAT-R), базовым функционалом расчётов, генерацией PDF-заключений и системой подписки.

**Ключевое решение (2026-04-26):** Web App вместо Local/Electron — проще разработать, легче монетизировать.

## Критерии готовности MVP

MVP считается готовым, когда:

- [x] Рабочая интеграция 1 методики (M-CHAT-R) с корректными расчётами
- [x] Экспорт в PDF работает без ошибок (99% случаев)
- [x] 5+ тестовых пользователей успешно сделали заключение
- [x] Нет критических багов (блокирующих работу)
- [x] Средняя оценка качества ≥ 4/5 от тестовых пользователей
- [x] Юридические риски оценены и минимизированы (152-ФЗ)
- [x] Система оплаты работает (можно подписаться)
- [x] Время от регистрации до первого заключения ≤ 10 минут
- [x] Retention (возврат через неделю) ≥ 40%
- [x] Приложение задеплоено на продакшн

## Риски и митигация

### Риск: Генерация PDF сложнее ожидаемого

**Вероятность:** Высокая
**Влияние:** Высокое

**Митигация:**

- Выбрать библиотеку на этапе Фазы 1
- Протестировать до разработки
- Увеличить срок (уже учтено: 3-4 недели)

---

### Риск: Пользователи не найдутся

**Вероятность:** Средняя
**Влияние:** Критическое

**Митигация:**

- Добавить маркетинговую фазу (Фаза 2.5)
- Найти амбассадоров заранее
- Запустить в профессиональных сообществах

---

### Риск: Нарушение 152-ФЗ

**Вероятность:** Низкая
**Влияние:** Критическое

**Митигация:**

- Консультация с юристом
- Минимизация данных (только ID/код, возраст)
- Шифрование данных

---

### Риск: Сроки увеличатся

**Вероятность:** Средняя
**Влияние:** Среднее

**Митигация:**

- Реалистичные сроки (8-11 месяцев)
- Редить функционал MVP (1 методика вместо 2-3)
- Разбить на версии (MVP 1.0, MVP 1.1)

---

### Риск: Пользователи не будут платить

**Вероятность:** Средняя
**Влияние:** Высокое

**Митигация:**

- Глубинные интервью на раннем этапе
- Понять реальную ценность
- Freemium модель (показать ценность до оплаты)
