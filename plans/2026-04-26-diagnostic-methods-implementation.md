# План реализации диагностических методик для СпектраМаяк

**Дата:** 2026-04-26
**Статус:** [ ] В разработке
**Цель:** Реализовать систему диагностических методик для личного использования (не для коммерции)

---

## Общий подход к реализации

### Стратегия легализации

Для каждой методики используем один из подходов:

1. **Открытые версии** — использовать бесплатные версии (M-CHAT-R, SCQ)
2. **Научные описания** — воссоздать на основе публичных научных статей
3. **Собственные аналоги** — создать вдохновлённые версии (не копии)
4. **Ручной ввод** — пользователь вводит данные из бумажных протоколов

**ВАЖНО:** Для коммерческого использования потребуется лицензирование. Этот план — только для личного/некоммерческого использования.

## ЭТАП 1: Золотой стандарт (диагностические)

### 1.1 ADOS-2 (Autism Diagnostic Observation Schedule)

**Статус:** Защищена авторским правом

**Решение:** Создать собственный аналог "СпектраМаяк-Оbservation" на основе:

- Научных статей об ADOS-2
- Публичных описаний модулей
- Собственных критериев оценки

**Что реализовать:**

- [ ] Модуль T (маленькие дети 12-30 месяцев)
- [ ] Модуль 1 (невербальные/однословные дети)
- [ ] Модуль 2 (фразовая речь)
- [ ] Сценарии наблюдения (игра, еда, социальные задания)
- [ ] Критерии оценки по категориям

**Источники:**

- Научные статьи:Lord et al. (2012), "The Autism Diagnostic Observation Schedule-2"
- Публичные описания на PubMed
- Открытые training материалы

**Срок:** 2-3 недели

### 1.3 CARS-2 (Childhood Autism Rating Scale)

**Статус:** Защищена авторским правом

**Решение:** Создать аналог "СпектраМаяк-Rating" на основе:

- Публичного описания 15 категорий
- Шкалы оценки 1-4

**Что реализовать:**

- [ ] 15 категорий оценки
- [ ] Шкала: 1 (возрастная норма) → 4 (сильное отклонение)
- [ ] Итоговый балл и интерпретация

  - 30-36.5: легкий/умеренный

## ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Структура данных

```prisma
// Дополнительные таблицы
model AssessmentMethod {
  id          Int       @id @default(autoincrement())
  name        String
  type        String    // diagnostic, screening, aba, fba, adaptive, etc.
  isPublic    Boolean
  isCustom    Boolean   // true = собственный аналог
}

model AssessmentResult {
  id              Int      @id @default(autoincrement())
  childId         Int
  methodId        Int
  date            DateTime @default(now())
  rawData         Json     // сырые данные
  scores          Json     // подсчитанные баллы
  interpretation  Json     // интерпретация
}

model FBAObservation {
  id              Int      @id @default(autoincrement())
  childId         Int
  date            DateTime
  antecedent      String
  behavior        String
  consequence     String
  duration        Int?     // секунды
  frequency       Int?
  intensity       Int?     // 1-10
}

model PreferenceAssessment {
  id              Int      @id @default(autoincrement())
  childId         Int
  date            DateTime
  method          String   // free_operant, paired_choice, mswо
  stimuli         Json     // список стимулов
  results         Json     // иерархия
}

model SkillsTracking {
  id              Int      @id @default(autoincrement())
  childId         Int
  skillName       String
  domain          String   // mands, tacts, echo, etc.
  date            DateTime
  level           Int      // 0-4
  ageEquivalent   Int?     // месяцы
  percent         Int?     // 0-100
}
```
