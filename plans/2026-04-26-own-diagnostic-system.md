## Обзор методики

**Название:** СпектраМаяк Диагностическая Система (СМДС)

**Вдохновение:** ADOS-2 (Autism Diagnostic Observation Schedule, 2nd edition)

**Возраст:** 12-48 месяцев

**Количество модулей:** 5 модулей

**Цель:** комплексная оценка риска расстройства аутистического спектра (РАС)

---

## Структура методики

### Модуль 1: Коммуникация (20 вопросов)

**Оцениваемые навыки:**

- Использование жестов
- Зрительный контакт
- Реакция на имя
- Инициация взаимодействия
- Поддержание диалога

**Примеры вопросов:**

1. Ребёнок реагирует на своё имя когда вы его зовёте?
2. Ребёнок использует жесты для общения (указывает, машет рукой)?
3. Ребёнок поддерживает зрительный контакт более 1-2 секунд?
4. Ребёнок инициирует взаимодействие с взрослым?
5. Ребёнок реагирует на эмоции взрослого?

**Подсчёт:**

- Каждый "НЕТ" ответ = 1 балл
- 0-3 балла = низкий риск
- 4-7 баллов = средний риск
- 8+ баллов = высокий риск

---

### Модуль 2: Речь (15 вопросов)

**Оцениваемые навыки:**

- Использование звуков
- Первые слова
- Простые фразы
- Понимание речи
- Эхолалия

**Примеры вопросов:**

1. Ребёнок произносит отдельные звуки?
2. Ребёнок говорит первые слова (мама, папа, дай)?
3. Ребёнок использует простые фразы (2-3 слова)?
4. Ребёнок понимает простые инструкции?
5. Ребёнок повторяет слова за взрослым (эхолалия)?

**Подсчёт:**

- Каждый "НЕТ" ответ = 1 балл (кроме вопроса 5 - там "ДА" = 1 балл)
- 0-3 балла = низкий риск
- 4-6 баллов = средний риск
- 7+ баллов = высокий риск

---

### Модуль 3: Игра (15 вопросов)

**Оцениваемые навыки:**

- Функциональная игра с игрушками
- Символическая игра (притворение)
- Совместная игра
- Интерес к сверстникам
- Стереотипии в игре

**Примеры вопросов:**

1. Ребёнок играет с игрушками по назначению (катает машинку, строит башню)?
2. Ребёнок притворяется (кормит куклу, разговаривает по телефону)?
3. Ребёнок интересуется другими детьми?
4. Ребёнок повторяет одни и те же действия с игрушками?
5. Ребёнок участвует в совместной игре с взрослым?

**Подсчёт:**

- Каждый "НЕТ" ответ = 1 балл (кроме вопроса 4 - там "ДА" = 1 балл)
- 0-3 балла = низкий риск
- 4-6 баллов = средний риск
- 7+ баллов = высокий риск

---

### Модуль 4: Стереотипии (10 вопросов)

**Оцениваемые поведения:**

- Двигательные стереотипии
- Сенсорные интересы
- Ритуальное поведение
- Упорство в неизменности

**Примеры вопросов:**

1. Ребёнок повторяет одни и те же движения (вращается, машет руками)?
2. Ребёнок проявляет необычный интерес к звукам/запахам?
3. Ребёнок расстраивается при изменении_ROUTINE?
4. Ребёнок выстраивает предметы в ряды?
5. Ребёнок фиксируется на частях предметов (колёсики, кнопки)?

**Подсчёт:**

- Каждый "ДА" ответ = 1 балл
- 0-2 балла = низкий риск
- 3-5 баллов = средний риск
- 6+ баллов = высокий риск

---

### Модуль 5: Адаптация (10 вопросов)

**Оцениваемые навыки:**

- Адаптация к изменениям
- Реакция на новые ситуации
- Сенсорная чувствительность
- Сон и аппетит
- Комфорт в повседневной жизни

**Примеры вопросов:**

1. Ребёнок легко адаптируется к новым местам?
2. Ребёнок проявляет чрезмерную чувствительность к шуму/свету?
3. У ребёнка есть проблемы со сном?
4. У ребёнка есть проблемы с аппетитом/питанием?
5. Ребёнок тревожится в новых ситуациях?

**Подсчёт:**

- Каждый "НЕТ" ответ = 1 балл (кроме вопросов 2, 3, 4 - там "ДА" = 1 балл)
- 0-2 балла = низкий риск
- 3-5 баллов = средний риск
- 6+ баллов = высокий риск

---

## Общий алгоритм подсчёта

### Шаг 1: Подсчёт баллов по каждому модулю

- Модуль 1 (Коммуникация): 0-20 баллов
- Модуль 2 (Речь): 0-15 баллов
- Модуль 3 (Игра): 0-15 баллов
- Модуль 4 (Стереотипии): 0-10 баллов
- Модуль 5 (Адаптация): 0-10 баллов

**Максимум:** 70 баллов

### Шаг 2: Определение риска по каждому модулю

- **Низкий риск:** 0-30% от максимума модуля
- **Средний риск:** 31-60% от максимума модуля
- **Высокий риск:** 61-100% от максимума модуля

### Шаг 3: Общий риск

**Низкий риск:** все модули = низкий риск
**Средний риск:** 1-3 модуля = средний/высокий риск
**Высокий риск:** 4+ модулей = средний/высокий риск

## Схема базы данных

### Таблица: `children`

```sql
CREATE TABLE children (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code VARCHAR(50) UNIQUE NOT NULL,
  age_months INTEGER NOT NULL,
  gender VARCHAR(10), -- male, female
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### Таблица: `assessments`

```sql
CREATE TABLE assessments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  child_id UUID REFERENCES children(id),
  method VARCHAR(50) NOT NULL, -- 'SPECTRADIAGNOSTIC'
  status VARCHAR(20) NOT NULL, -- 'IN_PROGRESS', 'COMPLETED'
  total_score INTEGER,
  risk_level VARCHAR(20), -- 'LOW', 'MEDIUM', 'HIGH'
  created_at TIMESTAMP DEFAULT NOW(),
  completed_at TIMESTAMP
);
```

### Таблица: `module_scores`

```sql
CREATE TABLE module_scores (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID REFERENCES assessments(id),
  module_name VARCHAR(50) NOT NULL, -- 'COMMUNICATION', 'SPEECH', etc.
  score INTEGER NOT NULL,
  max_score INTEGER NOT NULL,
  risk_level VARCHAR(20) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Таблица: `responses`

```sql
CREATE TABLE responses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID REFERENCES assessments(id),
  module_name VARCHAR(50) NOT NULL,
  question_number INTEGER NOT NULL,
  question_text TEXT NOT NULL,
  answer BOOLEAN NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## Техническая реализация

### Frontend (Next.js 14)

**Компоненты:**

- `DiagnosticForm.tsx` — форма с 5 модулями вопросов
- `ModuleProgress.tsx` — прогресс по модулям
- `DiagnosticResult.tsx` — отображение результатов
- `DiagnosticPDF.tsx` — генерация PDF

**State management:**

- React Context или Zustand для хранения ответов
- Промежуточное сохранение в localStorage

### Backend (Next.js API Routes)

**Endpoints:**

- `POST /api/assessments/start` — создать новую оценку
- `POST /api/assessments/:id/module` — сохранить модуль
- `GET /api/assessments/:id/result` — получить результат
- `GET /api/assessments/:id/pdf` — сгенерировать PDF

### Генерация PDF

**Библиотека:** `jsPDF` или `react-pdf`

**Процесс:**

1. Получить данные оценки из БД
2. Сформировать структуру отчёта
3. Сгенерировать радарную диаграмму
4. Сгенерировать PDF
5. Вернуть файл пользователю

## Научная обоснованность

### Источники

1. **ADOS-2 (Autism Diagnostic Observation Schedule, 2nd edition)**
   - Авторы: Catherine Lord, Michael Rutter, et al.
   - Золотой стандарт диагностики РАС
   - Используется как структурная основа

2. **МКБ-11 (Международная классификация болезней)**
   - Критерии диагностики РАС
   - Код 6A02

3. **DSM-5 (Diagnostic and Statistical Manual of Mental Disorders)**
   - Критерии диагностики РАС
   - Секция Autism Spectrum Disorder

4. **Современные исследования РАС**
   - Статьи по ранней диагностике
   - Мета-анализы скрининговых инструментов

### Валидация

**План валидации:**

1. Экспертная оценка от 3-5 специалистов
2. Пилотное тестирование на 10-20 случаях
3. Сравнение с клиническим диагнозом
4. Расчёт чувствительности и специфичности

**Срок:** после запуска MVP (июль-август 2026)
