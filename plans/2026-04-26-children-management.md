# План: Модуль "Управление детьми"

**Дата:** 26 апреля 2026 г.
**Статус:** Реализован ✅

## Описание

CRUD-модуль для управления профилями детей в системе СпектраМаяк. Пользователь может создавать, просматривать, редактировать и удалять профили детей. Все данные привязаны к аккаунту пользователя.

## Фазы реализации

### Фаза 1: API endpoints [x]

**Файлы:**

- `app/api/children/route.ts` — GET (список), POST (создание)
- `app/api/children/[id]/route.ts` — GET (просмотр), PUT (редактирование), DELETE (удаление)

**Требования:**

- Проверка авторизации через `auth()` из `lib/auth.ts`
- Возврат только детей текущего пользователя (userId совпадает)
- Валидация полей:
  - code: обязательно, уникален для пользователя
  - ageMonths: > 0
  - gender: male/female
- Обработка ошибок с русскими сообщениями

### Фаза 2: Страница списка детей [x]

**Файл:** `app/dashboard/children/page.tsx`

**Требования:**

- Таблица с колонками: ID, Возраст, Пол, Дата создания, Действия
- Кнопка "Добавить ребёнка"
- Использование дизайн-системы (bumaga-page, btn-primary)
- Обработка loading и error states
- Защита route (только авторизованные)

### Фаза 3: Форма создания ребёнка [x]

**Файл:** `app/dashboard/children/new/page.tsx`

**Требования:**

- Поля: ID ребёнка, Возраст (месяцы), Пол (radio buttons)
- Валидация на клиенте и сервере
- Ошибка если code уже существует
- Redirect на список после создания
- Кнопка "Отмена" для возврата к списку

### Фаза 4: Карточка ребёнка [x]

**Файл:** `app/dashboard/children/[id]/page.tsx`

**Требования:**

- Отображение информации о ребёнке
- Кнопки: "Редактировать", "Удалить", "Провести диагностику"
- Confirm dialog для удаления
- Проверка что ребёнок принадлежит текущему пользователю
- 404 если ребёнок не найден

### Фаза 5: Форма редактирования [x]

**Файл:** `app/dashboard/children/[id]/edit/page.tsx`

**Требования:**

- Предзаполнение формы текущими данными
- Валидация
- Redirect на карточку после обновления
- Проверка прав доступа

### Фаза 6: Обновление dashboard [x]

**Файл:** `app/dashboard/page.tsx`

**Требования:**

- Секция "Мои дети" с последними 3 детьми
- Ссылка на полный список `/dashboard/children`
- Кнопка "Добавить ребёнка" -> `/dashboard/children/new`
- Замена кнопок "Скоро" на рабочие

### Фаза 7: Тестирование [ ]

**Тесты:**

- Создать ребёнка через UI
- Проверить что он появился в списке
- Отредактировать данные
- Удалить ребёнка
- Проверить что пользователь видит только своих детей
- Проверить валидацию (отрицательный возраст, пустой ID)
