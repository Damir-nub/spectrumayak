# Технические планы реализации

Эта папка содержит технические планы реализации функций проекта СпектраМаяк.

## Правила работы с планами

1. **Один план = одна функция**. Каждый план описывает реализацию одной конкретной функции.
2. **Формат имени файла**: `YYYY-MM-DD-название-функции.md` (например: `2026-04-26-mchat-diagnostika.md`)
3. **Структура плана**: план делится на фазы. У каждой фазы есть статус:
   - `[ ]` - не выполнено
   - `[x]` - выполнено
4. **Итоговый блок**: в конце каждого плана должен быть блок с итогами:
   - Реализовано целиком: да / нет / частично
   - Что осталось сделать (если не целиком)
5. **Актуализация**: любой агент, работающий с планом, обязан его актуализировать:
   - Отмечать выполненные фазы
   - Дописывать что было сделано
   - Обновлять итоговый блок

## Назначение

Планы описывают **как** мы делаем проект - технические детали реализации, этапы разработки, проверки.

Для бизнес-контекста (зачем делаем, для кого) смотри папку [`.business/`](../.business/).
