## Обзор

**Цель:** Создать систему, которая генерирует **конкретные индивидуальные рекомендации** для родителей на основе профиля ребёнка по 5 модулям.

**Ключевое отличие от конкурентов:** НЕ "обратитесь к специалисту", а ПОШАГОВЫЕ ИНСТРУКЦИИ: что делать, если ребёнок кричит / не спит / не ест / не реагирует на имя / бьётся головой / плохо адаптируется к изменениям.

  - Временные рамки ("подождать 10 секунд", "если не помогло через 5 минут")

## Фаза 2: Алгоритм генерации рекомендаций

### Логика привязки рекомендаций к профилю

```javascript
// Псевдокод алгоритма

ЕСЛИ (модуль_коммуникация.реакция_на_имя < 1) {
    Добавитьrecommendation("реакция_на_имя_упражнение_1");

    ЕСЛИ (возраст < 24 месяца) {
        Добавитьrecommendation("реакция_на_имя_дотронуться");
    } ИНАЧЕ {
        Добавитьrecommendation("реакция_на_имя_расстояние");
    }
}

ЕСЛИ (модуль_адаптация.реакция_на_изменения < 2) {
    Добавитьrecommendation("подготовка_к_изменениям_за_1_день");
    Добавитьrecommendation("предупреждение_5_2_1_минуты");
}

ЕСЛИ (модуль_стереотипии.раскачивание > 2) {
    Добавитьrecommendation("альтернатива_качели");

    ЕСЛИ (раскачивание > 2 И интенсивное) {
        Добавитьrecommendation("прерывание_стереотипии");
    }
}

ЕСЛИ (модуль_адаптивное_поведение.сон < 1) {
    Добавитьrecommendation("ритуал_перед_сном");
    Добавитьrecommendation("пробуждение_ночью_инструкция");
}
```

## Фаза 3: Структура данных

### База рекомендаций

```sql
-- Таблица: recommendation_scenarios
CREATE TABLE recommendation_scenarios (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  scenario_key VARCHAR(100) UNIQUE NOT NULL, -- 'cries_at_home', 'not_sleeping', etc.
  title VARCHAR(200) NOT NULL,
  description TEXT,
  category VARCHAR(50), -- 'behavior', 'sleep', 'eating', 'communication'
  created_at TIMESTAMP DEFAULT NOW()
);

-- Таблица: recommendation_steps
CREATE TABLE recommendation_steps (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  scenario_id UUID REFERENCES recommendation_scenarios(id),
  step_order INTEGER NOT NULL,
  condition_text TEXT, -- "Если криочет дома"
  action_text TEXT NOT NULL, -- "Проверить подгузник"
  duration_minutes INTEGER, -- NULL или 5 (если есть временной лимит)
  next_step_if_fails UUID REFERENCES recommendation_steps(id),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Таблица: module_to_recommendations
CREATE TABLE module_to_recommendations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  module_name VARCHAR(50) NOT NULL, -- 'COMMUNICATION', 'SPEECH', etc.
  question_number INTEGER NOT NULL,
  score_threshold INTEGER NOT NULL, -- если балл < этого, добавить рекомендацию
  scenario_id UUID REFERENCES recommendation_scenarios(id),
  age_min_months INTEGER,
  age_max_months INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## Метрики успеха

1. **Полнота:** Охвачены 90% типичных ситуаций
2. **Конкретность:** Каждая рекомендация имеет пошаговую инструкцию
3. **Индивидуальность:** Рекомендации отличаются для разных профилей
4. **Понятность:** Родители понимают, что делать, без уточняющих вопросов
5. **Применимость:** Рекомендации можно выполнить дома без специального оборудования
